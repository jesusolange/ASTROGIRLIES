ASTROMED

IMPORTANTE: la app ya NO se abre con doble clic en index.html.
Ahora esta hecha con Vite y Preact y necesita un servidor de desarrollo o una compilacion.

COMO USAR (necesitas Node 22 o superior y pnpm)
1. pnpm install
2. pnpm dev          -> abre http://localhost:4321
3. pnpm build        -> genera la carpeta dist/ (lo que se publica)
   pnpm preview      -> sirve dist/ para revisarla

ARCHIVOS
  index.html              la pagina
  src/main.jsx            la entrada
  src/scripts/            un modulo por seccion (entrada: main.js)
  src/styles/             hojas de estilo
  public/assets/          imagenes y modelos 3D
  public/legacy/          paquetes ya compilados: PDF (astromed-pro.js) y astronauta 3D (astronaut3d.js)
  functions/              servidor opcional (cuentas y sincronizacion)
