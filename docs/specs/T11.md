# T11: Medical figures with a clear licence

Ticket 13 in `docs/tickets.md`, and the image part of GitHub issue 4.

## Why

The generated SVG illustrations look poor and specific medical figures (for example a dermatome map) are needed.
NASA does not publish these. Every figure in a submission must be reusable with credit.

## You own

- `public/assets/medical/**`
- `docs/references.md` (create it; you are the only worker editing it)
- `src/data/figures.js` (id, file, alt text, title, author, source URL, licence, licence URL)

You do not place figures into sections: other workers own those files. A later task wires them in from
`src/data/figures.js`.

## Do

1. List the figures the app needs. Walk the sections (Daily Checkup organs, Vision, Emergencies situations,
   Exercise, Protocols) and write the list at the top of `docs/references.md` with, for each: where it would be
   used and what it must show. Expected candidates: dermatome map, Amsler grid (can be drawn in code, no image
   needed), heart, lungs, kidney and urinary tract, brain, skeleton with common fracture sites, eye cross-section
   with optic nerve, pressure points or tourniquet placement, recovery position.
2. Source each one only from: Wikimedia Commons (including public-domain Gray's Anatomy plates), OpenStax Anatomy
   and Physiology (CC BY 4.0), Servier Medical Art (check the current licence on its site). Open the file's own
   licence page and read it; a search result or a thumbnail page is not evidence.
3. Accept only: public domain, CC0, CC BY, CC BY-SA. Reject NC and ND licences and anything unclear. For CC BY-SA
   say so explicitly in the reference (it obliges derived images to carry the same licence).
4. Download the accepted files into `public/assets/medical/`, prefer SVG, otherwise PNG or JPEG at most 400 KB each
   (resize if needed). Keep the original file name in the reference.
5. Record in `docs/references.md` and in `src/data/figures.js`: title, author, source page URL, licence name,
   licence URL, date accessed, and any change you made (resized, cropped).
6. Also move the 3D model credits from `README.md` into `docs/references.md` as a second table (copy them; do not
   edit `README.md`), and add the fonts and libraries you can identify from `package.json`.
7. Anything you could not source with a clear licence goes in a "Not sourced" list with what you tried.

Never use an image from a general image search, from a site that does not state a licence for that file, or one
you could not open the licence page for.

## Done when

- Every file in `public/assets/medical/` has a complete row in `docs/references.md` and an entry in
  `src/data/figures.js`, and every licence URL was opened by you.
- A contact sheet screenshot of all figures is in `docs/evidence/T11/` (a throwaway HTML page under `.tmp/` shot
  with `tools/shot.mjs --url file:///...` is fine).
