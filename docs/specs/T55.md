# T55: Mark AI-generated images

Owner decision: the five Emergency illustrations and the ARED, T2 and CEVIS exercise pictures are AI-generated
and must say so on screen.

## You own

- `src/components/ui/` (one new small component and its CSS rules in the kit stylesheet)
- `src/data/emergencies.js` (image entries only: add a flag, never change text)
- `src/components/emergencies/**` and `src/components/exercise/**` where those images render
- `docs/references.md` (the rows for these images)

## Do

1. A small **"AI-generated"** badge component in the kit: a compact label in a corner of the image (bottom left),
   readable in both themes over any picture (solid token background, 12px text or larger), not covering the
   medical content of the picture, `aria-hidden` with the image's `alt` text ending in "(AI-generated
   illustration)" so screen readers hear it once.
2. Mark the images with a flag in their data (`ai: true`) rather than by file name, and render the badge wherever
   a flagged image appears:
   - Emergency: `chest.jpg`, `drain.jpg`, `belly-rovsing.jpg`, `belly-murphy.jpg`, `dermatome.jpg`
     (`public/assets/emergency/`).
   - Exercise: the ARED, T2 and CEVIS pictures (`public/assets/ARED.png`, `T2.png`, `CEVIS.png` and
     `public/assets/exercise/`), wherever the training card shows them, large or as thumbnails.
3. `docs/references.md`: one row per image saying "AI-generated illustration, made for this project", and remove
   them from the "Not sourced" list. The Sources dialog lists them the same way if it reads that data.
4. Do not change the pictures themselves.

## Done when

- Every one of those images shows the badge in both themes, at 1440 and 390 wide, and no other image does.
- `pnpm test` and `pnpm build` pass. No committed screenshots.
