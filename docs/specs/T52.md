# T52: Urine samples in the lab result card

Owner request. The Immune lab result card takes saliva or blood; it must also take urine.

## You own

- `src/components/immune/**` (JSX only; T38 owns `immune.css` in this batch, so add no CSS or ask), `src/scripts/immune.js`,
  `test/immune.test.js`

## Do

1. Add "Urine" to the sample types beside saliva and blood.
2. The test-name and unit suggestions follow the sample type. For urine offer the usual units (mg/dL, mmol/L,
   µmol/L, g/L, nmol/mmol creatinine, mg/24 h) and common tests a crew may run (for example N-telopeptide, calcium,
   creatinine, specific gravity, pH), still allowing free typing of name and unit.
3. Do not add thresholds: a urine result is recorded and shown in Progress like the others, with no level unless
   an existing threshold already applies to that exact test.
4. Keep the stored record shape; add a `sample: "urine"` value only where the record already has a sample field
   (otherwise add `sample` as an optional field and read old records as before).

## Done when

- A urine result can be saved, appears in Progress, and old saliva and blood records still read.
- `pnpm test` and `pnpm build` pass. No screenshots.
