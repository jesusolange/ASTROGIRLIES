# T22: The mission lives in the profile, and only there

Batch 1. Today the mission can be chosen in three places and crew size cannot be chosen at all. The profile
becomes the single place for destination, crew size, start date and duration.

## You own

- `src/scripts/profile.js`, `src/components/profile/**`, `test/profile.test.js`

Do not edit the Environment or Mission risks pickers; T26 deletes those pages.

## Do

1. Add **crew size** to the profile form and record as `crew` (whole number, 1 or more). A record without it
   reads as 1.
2. Make **duration in days** an editable field of the mission (reuse the fields behind `totalFor` and
   `missionDayFor`). "Day n / X" everywhere uses it.
3. First run: the dialog cannot be dismissed. Remove "Later". Name, destination, crew size, start date and
   duration are required. Age, sex, weight and height stay optional (a card that needs them links to the profile).
4. "Menopause" is shown only when the selected sex is female.
5. Show the fields in three labelled groups: You, Mission, Body. Mission holds destination (`missionType`), crew
   size, start date, duration.
6. Remove any demo name or placeholder name ("Solange" and the like) from defaults and placeholders.
7. Field errors appear under the field and move focus to the first invalid field. No toast for validation.
