# T12: Split the page shell into an Astro layout and components

Follow-up to ticket 15 and GitHub issue 2. Starts after T02, T04 and T08 are merged (they edit `index.astro`).

## Why

`src/pages/index.astro` is one long file holding the whole shell. A developer who knows Astro expects a layout and
components. This task changes structure only: the rendered HTML must stay the same.

## You own

- `src/pages/index.astro`, `src/layouts/**`, `src/components/**`

## Do

- `src/layouts/Base.astro`: `<html>`, `<head>` (meta, title, CSS imports), `<body>` with a slot, the toast container,
  and the module entry script.
- Components, each a plain `.astro` file with no client framework: `IconSprite.astro` (the SVG symbols),
  `Sidebar.astro` (takes the list of nav items as data in its frontmatter and renders the buttons with a loop),
  `Header.astro` (the header bar with theme switch and profile icon, if present), `CheckupPage.astro`,
  `ExercisePage.astro` (exercise cards rendered from a small array), `Modal.astro`, `Footer.astro`,
  `LegacyBindings.astro` (the hidden elements old scripts still look up; say in a comment which script needs them).
- `index.astro` becomes a short file that composes these.
- Keep every `id`, `class` and `data-*` attribute: the scripts in `src/scripts/` find elements by them. Do not move
  any script logic and do not edit `src/scripts/**` or `src/styles/**`.
- Prove the HTML is unchanged: build before and after (`pnpm build`), normalise whitespace in `dist/index.html`
  for both, and diff them. Put the diff (empty, or the differences with a reason for each) in your report.
- Add a section "Project structure" to your report text for the coordinator to paste into `README.md`.

## Done when

- `index.astro` is under 60 lines and each component under 200.
- The normalised `dist/index.html` diff is empty or every difference is explained.
- `node tools/shot.mjs --strict` shows the same result as before your change, and screenshots of Daily Checkup and
  Exercise before and after are in `docs/evidence/T12/`.
